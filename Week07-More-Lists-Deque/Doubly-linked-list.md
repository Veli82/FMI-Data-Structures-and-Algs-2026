# Какво представлява:
Двусвързаният списък е като едносвързания, но всеки елемент освен стойността си и адреса на този след него, пази и адреса на елемента преди него. В двусвързания списък пазим указател към първия и към последния елемент. От всеки един елемент може да отидем напред или назад. Обхождането все още е линейно, но може да се движим и в двете посоки.


# Интерфейс:
### Предимства на двусвързаният списък спрямо едносвързания:
* **popBack/pushBack(val) - О(1)**
* освен **insertAfter** имаме **insertBefore** (същото и за remove)
* може да се обхожда и в двете посоки  
* операциите на структурата са симетрични

Като недостатък може да отбележим, че заема повече памет от едносвързания (и операциите са по-сложни).

# Реализация:
```cpp
struct node
{
    int data;
    node* next;
    node* prev;
}

class Doubly_linked_list
{
    node* first;
    node* last;
    //size_t size;
}
```
